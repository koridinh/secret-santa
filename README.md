# 🎅 Secret Santa

A cute, simple mobile web app for drawing Secret Santa with friends.

- The organizer enters everyone's names and taps **Bốc thăm** (Draw).
- Everyone opens the shared link on their own phone, types their name, and taps the gift box to see who they're buying for.
- Nobody gets themselves, and the results are encoded into the link, so no one (not even the organizer) can see the full list.

No server and no accounts needed: it's just one `index.html` file.
